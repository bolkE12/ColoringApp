# App Store Screenshots Guide

This guide will help you capture the perfect screenshots for your App Store listing.

## Required Sizes

### iPhone
You need screenshots for at least ONE of these sizes:

1. **6.7" Display** (iPhone 15 Pro Max, 14 Pro Max, 13 Pro Max, 12 Pro Max)
   - Size: **1290 x 2796 pixels**
   - Minimum: 3 screenshots
   - Maximum: 10 screenshots

2. **6.5" Display** (iPhone 11 Pro Max, XS Max, 11, XR)
   - Size: **1242 x 2688 pixels**
   - Minimum: 3 screenshots
   - Maximum: 10 screenshots

### iPad (Since your app supports iPad)

1. **12.9" Display** (iPad Pro)
   - Size: **2048 x 2732 pixels** (portrait)
   - Minimum: 3 screenshots
   - Maximum: 10 screenshots

## How to Capture Screenshots

### Option 1: Using iOS Simulator (Recommended)

1. **Install Xcode** (if not already installed)
   ```bash
   # Open App Store and install Xcode
   ```

2. **Start the app in Simulator**
   ```bash
   npm start
   # Press 'i' to open in iOS Simulator
   # Or: npx expo start --ios
   ```

3. **Select the right device size in Simulator**
   - Xcode → Window → Device → iPhone 15 Pro Max (6.7")
   - Or: iPhone 11 Pro Max (6.5")

4. **Navigate to each screen**
   - Home screen
   - Create screen (select two animals)
   - Coloring screen (color a hybrid)
   - Animal Pen (after saving a few)

5. **Capture screenshots**
   - Press `Cmd + S` in Simulator
   - Screenshots save to Desktop
   - Named like: `Screenshot 2024-11-15 at XX.XX.XX.png`

6. **Verify dimensions**
   - Right-click screenshot → Get Info
   - Should match required dimensions exactly

### Option 2: Using Real Device (Alternative)

1. **Run app on your iPhone**
   ```bash
   npx expo start
   # Scan QR code with Expo Go app
   ```

2. **Capture screenshots on device**
   - Press: Volume Up + Side Button (iPhone X or later)
   - Press: Home + Side Button (iPhone 8 or earlier)

3. **AirDrop to your Mac**
   - Select screenshots in Photos app
   - Share → AirDrop to Mac

4. **Resize if needed** (if your device isn't 6.7" or 6.5")
   - Use Preview or Photoshop to resize to required dimensions
   - Maintain aspect ratio

## Screenshot Enhancement Tips

### Do:
- ✅ Use vibrant, eye-catching colors when coloring animals
- ✅ Show partially completed work to demonstrate the process
- ✅ Include UI elements (tools, buttons) to show functionality
- ✅ Make sure text is readable (names, buttons)
- ✅ Use the most appealing animal combinations
- ✅ Ensure good lighting/contrast in screenshots

### Don't:
- ❌ Include personal information
- ❌ Show error states or bugs
- ❌ Use placeholder or test content
- ❌ Include network indicators or low battery
- ❌ Show loading states
- ❌ Include offensive or inappropriate content

## Screenshot Checklist

Before uploading to App Store Connect:

- [ ] Have at least 3 screenshots per required device size
- [ ] Screenshots are exactly the right dimensions
- [ ] Screenshots are in PNG or JPG format
- [ ] No personal information visible
- [ ] UI is in English (or your primary language)
- [ ] Content is appropriate for 4+ age rating
- [ ] Screenshots show the app's best features
- [ ] Screenshots are in logical order (tells a story)
- [ ] File names are organized (e.g., iphone67-1.png, iphone67-2.png)
- [ ] All screenshots showcase actual app content (no mockups)

## Uploading to App Store Connect

1. **Log in to App Store Connect**
   - https://appstoreconnect.apple.com

2. **Navigate to your app**
   - My Apps → Chimera Coloring → App Store tab

3. **Select device size**
   - iPhone 6.7" Display
   - Or iPhone 6.5" Display

4. **Upload screenshots**
   - Drag and drop in desired order
   - Reorder by dragging
   - Delete and replace as needed

5. **Repeat for iPad** (if supporting iPad)

6. **Save**

## App Preview Video (Optional)

If you want to create a video preview:

### Requirements:
- Duration: 15-30 seconds
- Format: M4V, MP4, or MOV
- Resolution: Same as screenshot dimensions
- Orientation: Portrait
- File size: Max 500 MB

### Content Ideas:

3. Create: Tap CREATE button, show hybrid appear (3s)
4. Color: Demonstrate fill tool coloring different parts (8s)

6. Save: Tap Save button, show success animation (3s)
7. Pen: Show saved animal in Animal Pen (3s)

- **Screen Recording** (iOS): Record device screen
